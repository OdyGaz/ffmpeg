# ffmpeg
Notes on ffmpeg


# 🤔 Τι είναι το FFmpeg και πώς μπορώ να το χρησιμοποιήσω για να μετατρέψω ένα βίντεο σε GIF χωρίς να χάσω την ποιότητα της εικόνας;


### Τι είναι το FFmpeg;

Το **FFmpeg** είναι ένα δωρεάν λογισμικό ανοιχτού κώδικα που λειτουργεί μέσω της γραμμής εντολών (Command Prompt στα Windows ή Terminal σε Mac/Linux). Χρησιμοποιείται για την επεξεργασία, μετατροπή, εγγραφή και αναπαραγωγή σχεδόν οποιουδήποτε αρχείου βίντεο, ήχου ή εικόνας. 

Παρόλο που δεν έχει γραφικό περιβάλλον (παράθυρα, κουμπιά και μενού), θεωρείται το πιο ισχυρό εργαλείο για multimedia, καθώς μπορεί να διαχειριστεί και να μετατρέψει τα πάντα με μερικές γραμμές κώδικα.

---

### Γιατί τα GIF συνήθως χάνουν την ποιότητά τους;

Τα αρχεία GIF έχουν έναν σημαντικό περιορισμό: **μπορούν να εμφανίσουν μόνο έως 256 χρώματα** ανά frame. Αν μετατρέψετε ένα βίντεο (το οποίο έχει εκατομμύρια χρώματα) απευθείας σε GIF με μια απλή εντολή, το FFmpeg θα προσπαθήσει να χρησιμοποιήσει μια γενική παλέτα χρωμάτων. Αυτό έχει ως αποτέλεσμα το GIF να φαίνεται "pixel-ιασμένο", με έντονο θόρυβο (dithering) και ξεθωριασμένα χρώματα.

Για να αποφευχθεί αυτό, χρησιμοποιούμε μια την παρακάτω τεχνική:
1. Το FFmpeg αναλύει πρώτα το βίντεο και δημιουργεί μια **εξατομικευμένη παλέτα 256 χρωμάτων** που ταιριάζει ακριβώς στα χρώματα του συγκεκριμένου βίντεο.
2. Στη συνέχεια, εφαρμόζει αυτή την παλέτα για να δημιουργήσει το GIF.

---

### Οδηγός Βήμα-Βήμα (Tutorial for Dummies)

#### Βήμα 1: Εγκατάσταση του FFmpeg
Αν δεν το έχετε ήδη εγκαταστήσει:
* **Για Windows:** Ο πιο απλός τρόπος είναι να ανοίξετε το PowerShell και να γράψετε την εντολή:
  `winget install Gyan.FFmpeg`
* **Για Mac:** Ανοίξτε το Terminal και γράψτε (απαιτείται το Homebrew):
  `brew install ffmpeg`

#### Βήμα 2: Προετοιμασία των αρχείων
1. Βρείτε το βίντεο που θέλετε να μετατρέψετε (π.χ. `myvideo.mp4`).
2. Μεταφέρετέ το σε έναν εύκολα προσβάσιμο φάκελο, για παράδειγμα στην **Επιφάνεια Εργασίας** (Desktop).

#### Βήμα 3: Άνοιγμα του Τερματικού
1. Ανοίξτε το **Command Prompt** (Γραμμή Εντολών) στα Windows ή το **Terminal** στο Mac στον φάκελο που έχετε το βίντεο.

#### Βήμα 4: Η Εντολή για Υψηλή Ποιότητα
Αντιγράψτε και επικολλήστε την παρακάτω εντολή στο τερματικό σας (αντικαθιστώντας το `myvideo.mp4` με το όνομα του δικού σας αρχείου) και πατήστε **Enter**:

```bash
ffmpeg -i myvideo.mp4 -vf "fps=15,scale=480:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" output.gif
```

Μέσα σε λίγα δευτερόλεπτα, θα εμφανιστεί στον φάκελο που που έχετε το βίντεο με όνομα `output.gif`.

---

### Τι σημαίνουν οι παράμετροι της εντολής; (Απλή εξήγηση)

* **`-i myvideo.mp4`**: Δηλώνει ποιο είναι το αρχείο εισόδου (input).
* **`fps=15`**: Ορίζει τα frames ανά δευτερόλεπτο. Τα 15 fps είναι μια καλή τιμή για να είναι ομαλό το GIF χωρίς να γίνει τεράστιο το μέγεθος του αρχείου. Αν θέλετε ακόμα πιο ομαλή κίνηση, μπορείτε να το βάλετε στο `24` ή `30`.
* **`scale=480:-1`**: Ορίζει το πλάτος του GIF σε 480 pixels. Το `-1` λέει στο FFmpeg να υπολογίσει αυτόματα το ύψος ώστε να μην παραμορφωθεί η εικόνα. Μπορείτε να αλλάξετε το `480` σε `720` ή `1080` αν θέλετε μεγαλύτερη ανάλυση (αυτό όμως θα αυξήσει πολύ το μέγεθος του αρχείου).
* **`flags=lanczos`**: Είναι ο αλγόριθμος που χρησιμοποιείται για την αλλαγή μεγέθους. Ο Lanczos προσφέρει εξαιρετική καθαρότητα στην εικόνα.
* **`split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse`**: Αυτό είναι το "μαγικό" μέρος. Χωρίζει το βίντεο σε δύο εικονικά κανάλια. Το πρώτο κανάλι δημιουργεί την εξατομικευμένη παλέτα χρωμάτων (`palettegen`) και το δεύτερο κανάλι εφαρμόζει αυτή την παλέτα (`paletteuse`) για να δημιουργήσει το τελικό GIF.

### Συμβουλή για το μέγεθος του αρχείου:
Τα GIF υψηλής ποιότητας μπορεί να γίνουν αρκετά μεγάλα σε μέγεθος (Megabytes). Αν το αρχείο σας βγει μεγαλύτερο από όσο θέλετε, μπορείτε να μειώσετε την ανάλυση (π.χ. `scale=320:-1`) ή τα frames (π.χ. `fps=10`).
